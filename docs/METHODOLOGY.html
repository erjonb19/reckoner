How every number in this pipeline is produced

A reference for the calculations, the data behind them, and the conditions under which each figure can and cannot be quoted. Written so a reader who disagrees with a number can find the exact step they disagree with.

Two rules, not one. Hospital Price Transparency covers every payer a hospital contracts with. Transparency in Coverage covers commercial group and individual market only — CMS explicitly exempts Medicare, Medicare Advantage, Medicaid and Medicaid managed care. Medicare Advantage and Medicaid rates therefore exist only in hospital-side files, and can be reported but never reconciled against a second disclosure.

02How data was acquired

Discovery is mechanical, not curated: hospitals are found through the file CMS requires them to publish, and what fails is recorded with a reason rather than dropped.

Hospital files

45 CFR 180 requires a cms-hpt.txt file at the root of each hospital's web domain, pointing at its machine-readable file. The crawler resolves that file for every domain on the target list, parses it tolerantly — key/value and JSON forms, hyphen and underscore spellings, HTML entities — and records the direct MRF links.

Every candidate is then sized with a HEAD request before anything is downloaded, falling back to a one-byte ranged GET where a CDN refuses HEAD. File size is a planning input, not something to discover mid-download.

Discovery outcome across 19 domains
OutcomeDomainsMeaning
Resolved11File found and parsed; 72 MRFs located
blocked7WAF challenge page — the file may well exist
soft-4041HTTP 200 serving the site homepage as HTML

The distinction between blocked and a genuine 404 is load-bearing. Seven domains return a Cloudflare interstitial; treating those as non-compliance would overstate what was observed. No attempt is made to defeat the challenge.

Reading at scale

  • Parse once, land curated. Each file is read a single time and a filtered slice written out. Raw files are never persisted.
  • Streaming throughout. Zip members are inflated from the local file header, since the central directory sits at the end of the file. A 2.8 MB zip in this corpus expands to 212 MB; the largest single file is 5.12 GB.
  • Resumable. Each load records ETag, Last-Modified and Content-Length. A re-run HEADs first and skips unchanged files without fetching a body.
  • Retried. Transient transport faults retry three times with linear backoff. A 404 or a parse error does not retry.

Reference and volume data

The DOH weight table, rate schedules and claims-payment workbook are downloaded as published spreadsheets and read by shape rather than fixed cell references, so an inserted row does not break the loader. SPARCS is paged from the Socrata API and cached locally.

03Code sets

Scope comes from the contracting sheet itself, so adding a service widens the ingest with no second list to keep in step.

A contracting sheet does not define a service as a list of codes. It defines it as a predicate over a claim line — a revenue code range, often intersected with procedure codes, sometimes with exclusions. All three forms are supported, and both conditions must hold on the same row.

Service definitions parsed from the rate sheet
FormServicesExample
Revenue codes only48Hemodialysis: 0820–0825, 0829
Revenue and procedure11Pacemaker: rev 0360–0361 … with CPT 33206–33208 …
With exclusions3Radiation: 0330, 0333, 0339 excluding CPT 61796–61800 …

Normalisation rules

  • Revenue codes are padded to four digits, never stripped. Hospitals publish 490 as often as 0490. Stripping the zero would collide revenue code 0470 with MS-DRG 470 — different services entirely.
  • Matching is type-aware. A revenue code only matches a code typed as revenue. Ignoring type admitted 70% of every file instead of 0.4%.
  • Ranges expand inclusively at the endpoints' own width. 0360-0361 yields two four-digit codes. En and em dashes are accepted, since sheets are pasted out of word processors.
  • APR-DRG codes carry severity in the code string — 194-2 — matching the DOH weight table key exactly. Severity is not optional: APR-DRG 001 is weight 6.1633 at severity 1 and 17.5054 at severity 4.

One correction to the source sheet, applied and logged. Radiation Therapy listed an exclusion range of 6320-63621, whose endpoints differ in width and cannot be expanded. Confirmed as 63620-63621, matching the same range in the Gamma Ray row it mirrors. The correction lives in a config file with its reason and who confirmed it — the spreadsheet stays the authority, and the loader reports every correction it applies.

04Curation and quarantine

Nothing raises. A row is either curated or quarantined with a reason code, and every batch is audited whether it succeeds or fails.

Reject reason codes
CodeApplied when
missing_payerNo payer name on the row
non_payer_rowSelf-pay or uninsured column — a standard charge, not a negotiated rate
missing_codeNo billing code
missing_vintageFile carries no last_updated_on; undated rates cannot be compared
no_rate_valueNo dollar, percentage or algorithm present
non_numeric_rateUnparseable amount, including NaN and Infinity
negative_rateAmount below zero
implausible_rateAbove $10,000,000 — a unit error, not a price
percentage_out_of_rangeOutside 0–1000%

Rows filtered for being out of scope are counted separately and never quarantined, so the reject rate stays a quality signal rather than a measure of how narrow the code set is.

Load guarantees

  • Atomic. Rows are staged and promoted only on completion. An interrupted download leaves nothing that looks loaded — verified against a real interruption at 21 of 72 files.
  • Idempotent. A batch is identified by source URL plus a SHA-256 checksum of the decoded bytes. Re-running an unchanged file is a no-op.
  • Superseding. A republished file replaces its own prior load rather than sitting alongside it and double-counting every rate.
  • Audited. Batch id, source, vintage, layout, bytes, checksum, rows in and out, reject reasons, attempts and status — for every file, success or failure.

05NY Medicaid payment model

A direct implementation of the calculation NYS DOH publishes in its Medicaid FFS and HMO Claims Payment Calculation workbook. Line numbers below are the worksheet's own.

Three payment paths. Every result carries its intermediate lines, because a total that cannot be traced back to the published methodology cannot be defended.

Inlier — the ordinary caseDOH “Inlier” worksheet
  1. 1Discharge case payment rate — facility schedule
  2. 2Service intensity weight — APR-DRG × severity
  3. 3Case-mix adjusted payment = 1 × 2
  4. 4Direct medical education — FFS only; MMC pays separately
  5. 5Capital per discharge
  6. 6Inlier DRG payment = 3 + 4 + 5
  7. 6bTeaching add-ons = 6 × IME% + DME, when included
  8. 7cAlternate level of care = ALC rate × ALC days
  9. 8Total inlier payment = 6 + 6b + 7c
Surcharge: 7.04% for indigent care, added only where the provider has not signed the election.
Transfer — paid per diem, cappedDOH “Transfer” worksheet
  1. 5Case-mix adjusted payment = rate × weight
  2. 6Statewide average inlier length of stay
  3. 7Average inlier cost per day = 5 ÷ 6
  4. 8Transfer adjustment = 100% where ALOS is 1 day, else 120%
  5. 9Transfer cost per day = 7 × 8
  6. 11Total per diem = 9 + capital per diem
  7. 12Transfer payment = 11 × days excluding ALC
  8. 17Capped = lesser of 15 or the full inlier DRG
  9. 19Total with ALC = 17 + 18
A transfer can never pay more than the full DRG would have. The cap is asserted by test, not assumed.
High-cost outlier — paid in additionDOH “High Cost” worksheet
  1. 3Net charges = gross − non-covered
  2. 5Converted to cost = 3 × high-cost charge converter
  3. 6cAdjusted threshold = APR-DRG threshold × ISAF
  4. 7aQualifies only if 5 > 6c
  5. 8Outlier payment = 5 − 6c
  6. 10Total = 8 + full inlier payment
Never applies to transfers. Without charges supplied, no outlier can fire and payment is understated on exactly the expensive cases outliers exist to cover.

Why geography dominates

The statewide base price is $7,460, but each facility's discharge rate is that price adjusted by its Institutional Specific Adjustment Factor — a wage equalisation term. The spread is large enough that any comparison ignoring it is wrong.

Teaching add-ons are not optional for revenue work. The managed care schedule states its rate is “excluding IME”, and lists IME% and DME as informational only — managed care pays them through a separate mechanism. IME runs 29.7% at NYU Langone against 5.2% at Ellis, so omitting them does not make a figure conservative, it makes it wrong in a way concentrated on teaching hospitals. The model reproduces the DOH worksheet exactly by default and adds them on request.

06Percent of Medicare

The unit contracting teams actually use, and not a lookup. A benchmark must match on fee schedule, code type, setting, geography and year.

Each code type routes to the schedule that prices it: MS-DRG to IPPS, CPT to the Physician Fee Schedule, HCPCS and APC to OPPS. APR-DRG routes nowhere — it is a state grouper Medicare does not price, and saying so is more useful than forcing a match.

Inpatient benchmarkIPPS
  1. aDRG relative weight — IPPS final rule
  2. bWage adjustment = labour share × wage index + non-labour share
  3. cBenchmark = a × standardized amount × b
IPPS parameters have no defaults in code. A stale standardized amount silently rescales every inpatient comparison, so the caller must supply them from a cited source.

Every failure returns a reason rather than a null, because the share of rates that cannot be benchmarked is itself a finding: not_dollar_denominated, unsupported_code_type, no_benchmark_for_code, no_geography_for_hospital, no_wage_index_for_area, vintage_mismatch, zero_benchmark.

Outpatient and professional benchmarks are gated. CMS puts the PFS relative value files behind an AMA CPT licence click-through. MS-DRG weights are CMS-owned and download freely, so inpatient benchmarking is automatable end to end; CPT-keyed schedules require a manual download after accepting the licence.

07Margin

A rate is not a result. Margin is what turns a price into a decision about whether a service line survives.

Margin over a book of businessper APR-DRG severity
  1. 1Cases = SPARCS discharges × payer share
  2. 2Payment per case — full payment model, outliers included
  3. 3Cost per case — SPARCS mean cost
  4. 4Margin = (2 − 3) × 1
Cases with no weight cannot be paid; cases with no cost cannot be judged. Both are counted separately rather than folded into the totals.

The first margin run was wrong in three separate ways, each of which produced a plausible looking figure. They are recorded here because the corrected numbers only mean something against them.

08Market position

A dollar figure alone is not a negotiating position. A percentile against a stated peer group is.

  • Percentile is the share of the peer group at or below the observed rate, computed within a single code — ranking a knee replacement against a blood panel is arithmetic dressed as insight.
  • Peer groups are always named on the result. Comparing a Manhattan academic centre to an upstate community hospital gives a number that is correct and useless.
  • Fewer than five peers marks the position unreliable rather than reporting a percentile that three observations cannot support.
  • Spread ranks services by the ratio between the dearest and cheapest rate — the shortlist a negotiator starts from.
  • Opportunity = gap to peer median × annual volume. This is the step that makes a percentile actionable: the 20th percentile on a service performed 4,000 times a year is a different conversation from one performed twice.

09Payer entity resolution

1,387 distinct payer and plan strings across ten hospitals, collapsing to roughly forty real contracting parties.

uhc, united healthcare, united and oxford are one company. Harder than spelling, the granularity differs between hospitals — one publishes Aetna ‖ All Commercial Plans, another ANTHEM ‖ Blue Access Large Group — so there is no one-to-one mapping to discover.

How it is built

  • A deterministic baseline runs first and is a real matcher, not a strawman. It resolves 835 of 1,387 strings, covering 73.7% of rate volume, at zero cost and zero latency. Any model-assisted matcher has to beat that number to earn its place.
  • The agent proposes, code disposes. A JSON schema constrains the shape of a response; deterministic validation constrains the vocabulary. A confident answer with no lexical overlap with the raw string is rejected before it can merge two contracts.
  • Abstention costs recall, never precision. A wrong merge is worse than a question, so precision regression disqualifies a matcher regardless of F1, and a gain under two points is treated as noise.
  • Low confidence routes to a human, and those decisions become the labelled set.
  • Every call is costed and timed, so the choice to use a model carries a number.

The queue that remains is the genuinely hard tail — provider-sponsored networks (Northwell Direct), union funds (Local 1199) and third-party administrators (POMCO, RMSCO) — which is exactly where a model may or may not earn its cost.

10Provenance rules

Every figure carries what it rests on, because the questions are always the same: how many rows, from when, what was excluded, and does it cover enough to matter.

Conditions that attach a caveat automatically
ConditionEffect
Sources more than 400 days apartNot comparable; differences may be a timing artifact
Fewer than 30 rowsNot a stable estimate
Under half of candidate rows survived filteringIncluded share reported alongside the figure
Under 25% of the hospital's bookCoverage stated explicitly
Single hospitalNot a market view

A figure is Reportable only when it clears both the row threshold and the vintage span. Everything else is quotable only with its qualifier attached — which the code emits rather than relying on anyone to remember.

The current corpus does not clear it. SPARCS 2021 against 2025 rate schedules is a span of roughly 1,550 days. Any margin figure combining them is Sampled and carries the vintage caveat. The volumes are a case-mix shape, reliable for weighting, and not a claim about current activity.

11Known limits

Stated here rather than discovered by a reader.

  • Geographic coverage is uneven. Hudson Valley and Western New York have no resolved hospitals; the Capital District has one. Seven systems are behind bot protection and need manual capture.
  • Payment is claim-based only. DSH, directed and supplemental payments are excluded. Those pools are largest at safety-net and academic hospitals.
  • Cost is a facility-and-DRG average, not per-case actuals. This screens service lines; it does not cost individual cases.
  • One vintage per hospital. Trend analysis needs a second snapshot, and hospital files update annually — a time problem, not a fetch problem.
  • APR-DRG weights are the July 2018 table, which remains operative for 2025 rates per DOH. That is correct, not stale, but it is worth knowing.
  • Payer-side reconciliation is not built. Transparency in Coverage ingest is the next phase; until then this is a hospital-side analysis, and Medicare Advantage and Medicaid rates could never be reconciled regardless.
  • This is a personal project. Deployed, scheduled, monitored and tested — but no real users or business decisions depend on it, and no claim otherwise should be made.
